## Set up a Backup

BorgBase supports three backup tools. Pick one to see the setup steps for your platform.

<CardGrid>
	<LinkCard title="Borg" href="/setup/borg" description="Command line with Borgmatic, desktop clients, Synology, Ansible and more. Sends backups over SSH." />
	<LinkCard title="Restic" href="/setup/restic" description="Initialize a repository and take a first snapshot with the Restic CLI. Sends backups over HTTPS." />
	<LinkCard title="Vykar" href="https://vykar.borgbase.com/" description="Built by BorgBase, with built-in scheduling and YAML configuration. Opens the Vykar documentation." />
	<LinkCard title="Not sure which one?" href="/setup" description="Compare the three tools and see which one fits your situation." />
